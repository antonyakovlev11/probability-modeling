# Вероятностный анализ и проверка выводов

<br clear="all">

## Вероятность оффера и ошибки интерпретации

Я проверял утверждения об эффективности обучения и шансах получить оффер. Разделил результаты опроса, условные вероятности и сценарную модель поиска.

При постоянной вероятности успеха 10% и независимых попытках **20 попыток дают 87,84%**, а для порога 95% нужны **29 попыток**. Это результат модели, а не обещание трудоустройства.

![Вероятность хотя бы одного оффера](offer-probability.png)

### Применённые навыки

| Навык аналитика | Как я его применил |
|---|---|
| Проверка знаменателя метрики | Отделил долю трудоустроенных среди ответивших от доли во всей исходной группе |
| Работа с условными вероятностями | Проверил, в какую сторону задана зависимость «навыки — оффер» |
| Формализация допущений | Задал независимость попыток и постоянную конверсию |
| Анализ чувствительности | Сравнил результат при конверсиях 2%, 5% и 10% |
| Объяснение ограничений | Отделил высокую вероятность от гарантии и связь от причинности |
| Python | Добавил проверяемые функции вероятности и числа попыток |

### Что я проверил

Из 500 учеников ответили 200, из них 156 сообщили о трудоустройстве. **78% — доля среди ответивших.** Результат неответивших неизвестен; показатель нельзя автоматически переносить на всех выпускников.

«85% получивших оффер знают SQL и Python» — это `P(навыки | оффер)`. Для `P(оффер | навыки)` нужен другой знаменатель и данные о кандидатах с этими навыками. Само утверждение также не устанавливает причинный эффект обучения.

### Модель и сценарии

`P(хотя бы один оффер) = 1 − (1 − p)^n`

| Конверсия попытки | Минимум попыток для вероятности ≥ 95% |
|---:|---:|
| 10% | 29 |
| 5% | 59 |
| 2% | 149 |

![Чувствительность к конверсии](attempts-sensitivity.png)

### Пример кода

```python
from offer_model import probability, attempts_for_target

print(f"Вероятность: {probability(0.10, 20):.2%}")
for conversion in [0.02, 0.05, 0.10]:
    print(conversion, attempts_for_target(conversion, target=0.95))
```

Полный файл: [offer_model.py](offer_model.py). Запуск `python offer_model.py` сохраняет расчётную таблицу `model-probabilities.csv`. Этот код я добавил при подготовке портфолио для повторения модели.

### Для каких аналитических задач это полезно

Проверка метрик воронки, интерпретация опросов, сценарные оценки конверсии и обсуждение неопределённости. В реальном поиске я бы отдельно измерял переходы между этапами и проверял, сохраняется ли конверсия.

### Ограничения

Конверсии 2%, 5% и 10% заданы как сценарии. Попытки в реальном поиске могут зависеть друг от друга; после отказов параметры модели сами по себе не улучшаются. В этом кейсе нет оценки причинного эффекта курса или полноценного A/B-теста.
